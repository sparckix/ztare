Algebra checks. From
`a_{n+1} = λ^{-(n+1)/3} b_{n+1}` and
`a_{n+1} = λ^{-1} a_{n-1}² / a_n`:
RHS exponent =
`-1 - 2(n-1)/3 + n/3`
`= -1 - 2n/3 + 2/3 + n/3`
`= -1/3 - n/3`
`= -(n+1)/3`.
So the λ-prefactor cancels exactly and `b_{n+1} = b_{n-1}² / b_n`.

2. PASS  
For the stated forward KP/Cheskidov dyadic model, stationary inertial balance is exactly `k_n a_{n-1}² = k_{n+1} a_n a_{n+1}`. The index convention differs from the common `2^{j-1}, 2^j` presentation only by a common λ factor in the `j` equation, so the zero-balance recursion is unchanged. This does not cover mixed Obukhov/backscatter variants.

3. PASS

Correct only for the reduced algebraic fixed-flux recurrence. A simple unit root means no secular `n·1^n` term in the linear log recurrence, and because the log recurrence is exactly linear there is no nonlinear beta term inside that reduced object.

Must-fix: calling this “β ≡ 0” for the deterministic dyadic surrogate is too broad.
