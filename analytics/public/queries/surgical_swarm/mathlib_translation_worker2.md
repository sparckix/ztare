## Handoff Recommendation

1. For the existing Track B LSC adapters, start with `Filter.le_liminf_iff'` and `lowerSemicontinuous_iff_le_liminf`. These directly match the epsilon/eventual shape already present in `ns_gp216_limit_lsc_obligation.lean`.
2. For defect-measure relaxation, do not look for a direct Young-measure theorem. Use the probability-measure/Portmanteau layer as the closest Mathlib substrate, but record the missing Young-measure/barycenter/concentration map as a real gap.
3. For quartic/phase product charging, prefer the Holder/Young integral lemmas and matrix/norm lemmas as small local steps. Keep the quartic coercivity theorem separate; Mathlib primitives only price local algebraic pieces.
4. For Sobolev control, only claim the smooth compact-support finite-dimensional statements that Mathlib actually has. Any Rellich/profile-decomposition/NS compactness step remains an external analytic obligation.
