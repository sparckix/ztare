## HIGH findings

**H1. StateInterner conflates "interned" with "visited" — novelty collapses to 0 after any goal/progress search.**
`frontier_codec.py:216` — `batch_novelty` returns 0 for any grid whose key is in `_key_to_id`; min-hamming at :223 runs over the whole matrix. But `plan_to_goal` (planner.py:96-98) and `plan_progress` (planner.py:363-365) use the same shared `_pg_interner` as a dedup arena, interning every **simulated** successor; `pursue_goal` passes one interner to all (planner.py:871/903/1032/1053/1062/1074). Failure: `act_and_learn` (planner.py:1283, raw path) runs `plan_progress` for two replans, interning up to 5,000 simulated states; on replan 3 the novelty injection (planner.py:1046-1054) calls `plan_novelty` → every model-reachable state scores as visited → `best_novelty=0` → premature `plan_exhausted`. The abstract path is safe — `AbstractCarrierInterner` separates `intern` from `mark_visited` (frontier_codec.py:282-305); StateInterner lacks that split.

**H2. `_ensure_interners_synced` slices a Python set by positional cursor — the exact pattern the same diff documents as unsound.**
planner.py:624-641 does `list(_vset._raw)[_pg_interner_seeded:]` and `list(_vset._images["abstract"])[_pg_abs_interner_seeded:]`; both are sets (`image_set.py:134`, `:168`) whose iteration order permutes on resize. reachability.py:55-66 (FIX A, same uncommitted diff) explicitly rules the positional cursor unsound for sets. Failure: a live-visited carrier permutes into the processed prefix, never `mark_visited`, and `plan_novelty` early-returns it as "first unseen abstract carrier" (planner.py:317-328) → live steps re-visiting a known state + false `first_unseen_abstract_carrier` acquisition-routing receipts.

**H3. coverage_planner plans from the target's own representative — every plan is degenerate `[target_action]`.**
coverage_planner.py:259, :307, :368 call `_plan_to_carrier(champion, rep, …, target_carrier, …)` where `rep = reachable.get(target_carrier)`, so `alpha(start)==target_carrier` by construction and :152-153 returns `[target_action]` immediately. `execute_plans` executes that one action from `adapter.reset()` state (:392-401), almost never in the target class → `hole_witnessed=False`, and `plan_found` in `coverage_debt.jsonl` receipts is vacuously true whenever a representative exists. The W-method machinery never actually navigates to a hole. (`plan_to_hole` :282-311 has zero callers anyway.)

**H4. Non-commutation detection can miss aliasing at depth ≥ 2 under a dominance merge.**
factored_search.py:130 `transition_images` keyed per `(source_key, intervention)` but only populated for **expanded** nodes; a dominance-pruned node (`admitted`, :226-280) is checked only by `dominance_counterexample` (:132-224) — a one-step forward-simulation check. Failure: concretes s1, s2 share `dominance_key`, all one-step images agree, but grandchildren diverge (a one-shot rule whose footprint test flips after an intermediate write); s2 pruned, the goal edge reachable only through s2 never found, search returns `projected_frontier_exhausted` — which planner.py:757-759 records as `exhaustive: True` (unreachability-under-quotient verdict), no counterexample emitted. Guard is real but strictly weaker than the bisimulation it prices; docstring (:95-103) overstates it. Related: the image key omits time while `predict` is time-dependent — a merely time-varying law surfaces as `projection_noncommuting` and permanently fences the projection (planner.py:835-850): fail-closed, but the receipt blames the wrong defect class.

**M5. ## Top 3 remediations

1. **Split "interned" from "visited" in `StateInterner`** (mirror `AbstractCarrierInterner`'s `mark_visited`/visited-id set; `batch_novelty` consults only visited ids/mask). One chokepoint fix kills H1 for all three planners without unsharing the arena.
2. **Replace the positional set-cursor sync with a write-point hook**: intern/mark carriers at the single place they enter `_vset`/`visited_store` inside `pursue_goal`'s step loop; delete `_ensure_interners_synced` (H2) — provably ordered, matches the FIX A rationale already in the diff.
3. **Fix coverage_planner to plan from the actual start state** to the target carrier instead of from `reachable[target_carrier]` (H3), making `plan_found` meaningful and `execute_plans` actually navigate. Close behind: gate the capitulation flip on `not terminal_identity_defined` and route post-capitulation novelty through `coverage_fn` (M1/M2).
