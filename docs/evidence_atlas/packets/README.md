# Review Packets

> **Up:** [Evidence Atlas](../README.md)

These are not new experiments. They are external-facing packets assembled from
existing public artifacts so a reviewer can inspect a claim without traversing
the whole repository.

Here, **packet** means a reviewer-facing evidence dossier. It is different from
a **project intake** file, which is the pre-kernel handoff consumed by `ztare
project intake`, `ztare autoresearch trace`, and `ztare autoresearch run
--preflight-only`.

## What Counts As A Packet

A packet should be concrete enough to answer:

- what is claimed;
- what evidence level the claim reaches;
- where the primary artifacts live;
- what command or reproducible anchor exists;
- what the packet does not claim;
- what would falsify or upgrade the claim.

If a packet cannot answer those questions from public files, it should remain
listed in [Packet Coverage](../packet_coverage.md) as missing or partial.
