# ZTARE, Obsidian Vault Home

This file exists only so the repository opens cleanly as an Obsidian vault
(graph view, backlinks, outline). It is a signpost, not content. The
canonical entry point is `README.md`; nothing here is a second source of
truth.

Start here:

- **[README.md](README.md)** , the canonical entry point (what the
  measurement says, what transfers, where to go).
- **[Documentation map](docs/README.md)** , every doc by layer and
  maturity. Each doc carries an `> **Up:**` breadcrumb back to this map,
  so the tree is walkable in both directions.
- **[Tooling map: scripts/](scripts/README.md)** and
  **[analytics/](analytics/README.md)** , every script and data folder,
  one line each, navigable without opening source.
- **[Agent instructions](AGENTS.md)** , the standing rules both agents read.
- **[Papers](papers/README.md)** and the
  **[experiment board](research_areas/ZTARE_BOARD.md)** , results and the
  durable record.

Navigation convention: links are relative Markdown links, so they render
identically on GitHub and in Obsidian. Wikilinks (`[[ ]]`) are not used as
the backbone because they do not render on github.com.
