# Review — autoformalization + faithfulness leg

Cluster: `autoformalize.py` (3,314, in full), `autoformalize_notes.py` (driver+gates ~1,200 of 2,746), `certified_faithfulness.py`, `faithfulness_store.py`, `formalization_admission.py`, `blueprint_lint.py`, `definition_contract.py`, `conservative_definition.py`, `def_denotation.py`, `judge_panel.py`, `cross_voting.py`, `semantic_premise_shelf.py`, `source_implication_oracle.py`, `canonical_reelaboration.py` + no_good_store, export_training_corpus, prompts (targeted). ~8,000 LOC read. 5 module selftests + 6 corpus/ledger probes run; every production caller of the gate traced.

## Verdict: certified or judge-vibes?

**Judge-vibes at admission, kernel only at proof time — and the certificate leg is both unwired and a dead instrument on this box.**

- `certified_faithfulness.py` (3-verdict z3/Lean leg) is honest code — typed verdicts, refute-first, fail-closed, dead-instrument guard — but **no production path calls it**. `faithfulness_gate`/`autoformalize_and_solve` never invoke it; only agent-optional `agent_tools` "certify" and demo scripts do. `crossvote_enabled()` (cross_voting.py:407) has zero callers.
- Empirical: **z3 and sympy are not installed** — `certified_faithfulness --selftest` fails 16/22; every certificate call returns OUT_OF_FRAGMENT. The certificate tier is currently theoretical.
- What actually gates a first-seen NL in production (`autoformalize_refine._verify`, autoformalize.py:829-832): compile + triviality + substrate-infidelity (campaign only) + **majority-of-3 samples of ONE model family** (gemini default) on the roundtrip. `structural_faithfulness(expected=None)` is advisory-True (291-297). battery_fn/crossvote_fn/consistency_fn never supplied by any caller — the crossvote conflict-record at 2836-2840 is unreachable dead code. Judge panel + Dawid–Skene default-off; `judge_panel_votes.jsonl` doesn't exist. Live: 493 judge rows in `faithfulness_roundtrip_observations.jsonl` (31% reject, 22 split votes), all from `_observe_roundtrip` (1145-1172), the only writer.

## Findings

**F1 — Opinion promoted to permanent certificate via the store.** autoformalize.py:2896-2904 deposits `confirmed=True` **before solving**, on any firewall admit — a 2/3 single-family LLM vote. On re-seen NL, `confirms()` skips both the judge AND the structural reference comparison (2704-2732); reference-reuse (2760-2770) feeds the stored statement verbatim. Nothing persists *how* the admit happened (`source="firewall_admit"` regardless; checks dict dropped). One charitable vote permanently immunizes the pair from faithfulness re-litigation (only compile/triviality re-run). Deliberate (#105 fix), but it is exactly "downstream treats opinion as certificate."

**F2 — Roundtrip structurally blind to definitions.** Since the 2026-07-05 `_claim_signature` change (1548-1552) the back-translator sees only the last decl's signature — def bodies are never back-translated. `detect_def_shells` catches only bare-constant shells; per-def LLM judge behind `def_faithfulness=False` in every production caller (`_default_attack`, autoformalize_notes.py:416). `def_denotation` (well-built, targets exactly this decoy class) runs post-close, advisory, theory-first only (autoformalize_notes.py:627-703). Failure: off-campaign define_then_state with a non-constant wrong-object def (a predicate quietly encoding a weaker notion) → theorem signature back-translates faithfully → admitted → "closed" a different problem. On-campaign, `substrate_infidelities` (565-588) covers only re-declared substrate names.

**F3 — #105 name-brittle prior-confirmed: fixed, verified.** `confirms()` routes through `normalize_statement_equiv` recomputed on stored statements (faithfulness_store.py:66-88, 290-309); selftest passes name-change, preamble, substrate-fingerprint-scoping cases. Residual: `confirms()` does not consult `statement_false` keys the way `reference()` does (209-215 vs 301-308) — a kernel-refuted rendering can still skip the judge; ¬G re-catches downstream (wasteful, not unsound).

**F4 — Selftest pollutes the production refutation ledger and the training corpus.** `autoformalize._self_test` → `autoformalize_and_solve` (mock solve returns `falsified`) → `_record_statement_false_no_good` (2349-2366) writes to the hardcoded `OUT_DIR` (solver_core.py:108, no env override). Verified live: `theorem t : FalseRender := by sorry` / "counterexample at x=0" sits in `analytics/public/queries/solver_lane_no_good_store.jsonl` and was **exported into `falsification_corpus.jsonl` as a training row**. Recurrence of the known gate-ledger-selftest-pollution class. The exporter's `r.get("confirmed", True)` (export_training_corpus.py:224) is vacuous — the store never persists a `confirmed` field (all 23 statement_false rows: None).

**F5 — Corpus integrity (measured, α-key = the exporter's own normalizer):**
- `faithfulness_discriminator_corpus.jsonl` is **single-class** (166/166 "unfaithful"); positives only implicit in the autoformalization corpus. Worse: the recorded `statement` for alteration classes is the **original goal** (`_ngs.record(goal, ...)`, solver_core.py:5200) — the altered probe (the actual unfaithful artifact) is not in the row, so rows label faithful originals "unfaithful". 8 rows aren't statements (`conjecture_no_advance`, `apr_target_close`, …); 12 witnesses are the generic template string.
- **Cross-corpus label contamination:** 21 statements appear both faithful-positive and "unfaithful"; 16 confirmed-faithful statements also appear kernel-refuted in the falsification corpus; 4 statements both proven (prover) and refuted (falsification) — substrate-context-free statement text can't disambiguate.
- `autoformalization_corpus.jsonl`: **61/227 (27%) NLs truncated mid-word at 400 chars** (faithfulness_store.py:150 `nl[:400]` — the truncation class the 2026-07-03 fix removed for statements but kept for NL). 30 duplicate statements across NLs; 12 same-NL→different-statement groups (contradictory supervision). No verification receipts ("confirmed" = LLM opinion). Prover rows are fine (recompilable_probe + checker + ts). 20 rows carry `iso_lemmaN` auto-names (dedup name-agnostic so correct; noisy as targets).

**F6 — Uncommitted diff (autoformalize.py): good.** Timeout-ceiling clamp + removal of the `max(timeout_s, 360)` floor correctly honor the role-contract/provenance ceiling. Watch: `formalize_oneshot` budget 240s means interactive formalize loses 120s vs its tuned 360 — monitor formalize-timeout rates. Minor: malformed `ZTARE_LEANMILL_ROUNDTRIP_TIMEOUT_S` raises uncaught ValueError → blanket "round-trip errored ⇒ NOT admitted" (fail-closed but mislabeled dead instrument).

**Minor/iatrogenics:** judge_panel DS item key uses randomized `hash()` (judge_panel.py:163) — same item becomes distinct DS items across processes; `panel_models()` precedence config-over-env, opposite of `_roundtrip_model`'s env-first; `ZTARE_LEANMILL_ROUNDTRIP_MODEL=claude` would make judge+formalizer same-family (cross-family requirement unenforced); stale committed duplicate tree `src/src/ztare/leanmill/solver/` (June 11 copies). Clean: formalization_admission, canonical_reelaboration, governed_def_revision_gate, blueprint_lint, definition_contract, conservative_definition, source_implication_oracle, semantic_premise_shelf (typed, fail-closed where load-bearing, advisory where declared; selftests pass).

## Top 3 remediations

1. **Rebuild the corpus with provenance filters** (export_training_corpus.py): record the *altered probe* (not the original goal) in discriminator rows; drop non-statement goals and selftest artifacts (root fix: guard `_record_statement_false_no_good`/OUT_DIR writes when solve_fn is injected; delete the FalseRender row); remove the `nl[:400]` cap; add a cross-corpus consistency pass (a statement may not simultaneously be faithful-positive, unfaithful, and refuted without a flag).
2. **Persist verdict provenance in the faithfulness store** (judge votes/method vs certificate, per record) plus a re-judge policy, so a 2/3 single-family opinion is not permanent immunization; minimum: make `confirms()` exclude `statement_false` keys like `reference()` does.
3. **Close the definition blind spot at admission:** default `def_faithfulness=True` for multi-decl blobs (or back-translate defs referenced by the conclusion alongside `_claim_signature`); install z3/sympy — the certificate leg is a dead instrument on this machine, so even the agent-optional `certify` tool silently returns OUT_OF_FRAGMENT.
