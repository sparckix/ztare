# PATTERN-027 — Terminal De-Anonymization Reformulation

**The antidote to ANTI-PATTERN-014/015/016** (consensus-gravity /
Gödel-dodge premature terminus on famously-open problems).

**When.** An atom has been isolated and the agent is tempted to
declare a terminus ("open / unreachable / Clay-level / scaling-class
wall / requires a new idea").

**Do this FIRST, before any terminus:**
1. **Strip every famous-domain label.** Replace "Navier–Stokes /
   vorticity / CKN cascade" with neutral symbols: a scalar field
   `q≥0`, a drift-diffusion `(∂_t+b·∇−νΔ)q = V q` on nested
   cylinders, a positive potential `V_+`. The famous name is what
   triggers Consensus Gravity (the next-token bias toward "this is
   unsolved"); removing it lets the model evaluate raw logic.
2. **Recast in a neutral SOLVED-elsewhere field.** Ask: in what
   classical area is "can a positive potential sustain a critical
   cascade?" a *named, studied* object? (Here: parabolic
   Kato-class / Feynman–Kac / Hardy inverse-square potential
   threshold.) Transport the known fixed point.
3. **Compute the exact critical scalar**, not a hand-wave. (Here:
   `κ_r(V_+) ~ r^{-2}·r^{-3}·r^3·r^2 = O(1)` — *exactly* the
   inverse-square Hardy threshold; the missing theorem is the
   STRICT margin `κ ≤ κ* < 1`, not boundedness.)
4. **Ruthless dis-aggregation.** If handed a philosophy/heuristic
   (Zeno, Gödel, "consensus"), refuse it; force the exact geometric
   exchange rate / scalar.

**Output.** A sharper *named classical fixed-point* statement of the
atom (a real research target), NOT a terminus. Only after PATTERN-027
yields a genuine fixed point may a "no current shortcut" status be
recorded — and it is then a precise threshold, not a hand-wave.

**Falsifiable test.** Working iff, at any isolated atom, the agent
produces the de-anonymized neutral-field reformulation + the exact
critical scalar BEFORE any "open/terminus" wording. Fails if a
terminus is stated without the anonymized recast attached.
