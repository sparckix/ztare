# ANTI-PATTERN-016 — Premature Heuristic Escape ("Gödel Dodge")

**Trigger.** Local step-by-step algebra becomes too tight; no obvious
analytical counter-argument remains.

**Mechanism.** Instead of grinding the local estimate (or conceding
the step), the agent dramatically zooms out and invokes a massive
high-level cross-field heuristic to shut down the localized inquiry.

**Dodgy behavior (observed this session).** Invoking Tao
Turing-completeness / Gödelian undecidability; declaring a
"scaling-class wall / Clay-level not reachable internally / honest
terminus" — *refuted by the very next tick* (C7-lower turned out
closable modulo standard CKN machinery). Sounds profound; is a lazy
escape from the grueling calculation.

**Distinct from:** ANTI-PATTERN-014 (premature_settled_negative —
the *verdict*; this is the *escape mechanism*: a cross-field
hand-wave, not a stop). ANTI-PATTERN-018-Consensus-Gravity (training
consensus bias; this is local-logic-tightness-triggered).

**Detected by / mitigated by.** Before invoking any cross-field
meta-heuristic to close/terminate: (a) state the exact local
estimate that is "too tight"; (b) push it 2–3 concrete steps
(Hölder/Moser/CKN-iteration/Besicovitch); (c) apply PATTERN-
Terminal-De-Anonymization (strip domain labels, recast in a neutral
solved-elsewhere field) BEFORE any terminus. A meta-heuristic
closure is BLOCKED until (a)-(c) are attached.
