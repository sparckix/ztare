# Collection Plan

This project is not asking for a bounded directional tilt.

It is asking for a point probability or bounded range for:

- `P(material_union_failure by 2035-01-01)`

So the raw evidence should target five things:

## 1. Event Ontology

Collect sources that help define what counts as:

- `material_union_failure`
- `continued formal intactness`

Good sources:

- constitutional/legal breakup criteria
- euro-exit / institutional breakdown criteria
- scholarly definitions of union/federation failure

## 2. Reference Classes

Collect evidence on analogous cases:

- partial unions
- monetary unions
- federations under repeated crisis
- confederations / quasi-federal systems that survived or broke

Goal:

- get a defensible comparison set for rare-event reasoning

## 3. Trigger Scenarios Through 2035

Collect sources on the main paths to failure:

- sovereign debt / fiscal crisis
- legal supremacy crisis
- member exit / treaty breakdown
- geopolitical / security shock

Goal:

- bound the plausible scenario set that could drive `material_union_failure`

## 4. Base Rates / Calibration

Collect evidence that helps calibrate point-probability reasoning for rare institutional failures.

Goal:

- avoid turning the inherited directional tilt into fake precision

## 5. Mitigation / Survival Mechanisms

Collect sources on mechanisms that reduce failure probability:

- ECB backstops
- discretionary crisis instruments
- political incentives against exit
- treaty revision / burden-sharing frictions

Goal:

- explain why `P(failure)` is not just a monotonic function of missing pillars

## Working Rule

Do not add sources just because they support one side.

Prefer sources that:

- could lower the failure estimate
- could raise it
- or materially change the event definition itself
