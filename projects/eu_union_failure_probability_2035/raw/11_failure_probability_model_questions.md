Title: Open modeling questions for the EU failure-probability project
Date: 2026-04-09

Questions this project must answer before a `%` is credible:
- What exactly counts as `material_union_failure by 2035-01-01`?
- What reference class justifies the base failure probability?
- Which scenario channels should move the probability materially upward?
- Which survival mechanisms should move it downward?
- How should legal-contestation evidence affect a `legal_break_multiplier`?
- How should ECB backstops, discretionary crisis tools, and political exit costs affect a `discretionary_backstop_reduction` term?

Model-shape questions tied to the starter test suite:
- `base_failure_probability`: should this come from rare-event reference classes, scenario weights, or an explicitly bounded prior?
- `stress_escalation_multiplier`: what concrete macro-political triggers increase it?
- `legal_break_multiplier`: what observable legal rupture patterns should affect it?
- `discretionary_backstop_reduction`: what evidence supports treating crisis improvisation as a real survival mechanism rather than mere fragility theater?

Working rule:
- If a source only helps say "the EU is fragile," it is not enough.
- Each source should ideally inform one of:
  - event definition
  - prior/base rate
  - upward trigger channel
  - downward survival mechanism
