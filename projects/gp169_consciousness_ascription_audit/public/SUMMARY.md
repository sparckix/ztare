# Consciousness-ascription audit: a scope result, not a verdict

Public digest of the `gp169_consciousness_ascription_audit` substrate
probe. Iteration logs stay internal; this is the honest result. Note
the object here is the auditing protocol, not a claim about machine
consciousness.

## The question

If an auditor plants a suite of bridge-failure stressors and a system
passes them, does that license a general "low concern" conclusion
about the ascription bridge?

## The result

The weak assumption is rejected. A planted stressor suite cannot be
certified complete over real bridge failures (unknown unknowns,
distributional shift, adaptive adversaries). The repair is a category
shift: the stressor set certifies only a bounded transport/envelope
claim. Passing it does not imply general validity. It implies
identification-admissibility only inside a certified environment
class, and only when an environment check and an adversarial check
also pass. Unknown unknowns are not "covered"; they are converted into
explicit scope failures unless independently shown to lie inside the
certified envelope.

## Status

A completed epistemic-discipline result: it tightens what a
pass-of-the-suite is allowed to license. It makes no claim about
whether any system is conscious. Single operator, in-system rubric;
the value is the forbidden inference it removes.
