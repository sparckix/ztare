# Project Charter

## Core Question

Can a partially integrated union remain durably intact, and which missing pillars are actually load-bearing for a durable equilibrium rather than a pattern of fragile but repeated crisis preservation?

## Out Of Scope

- validating only one narrow load-bearing mechanism in isolation as if it answered the whole project
- claiming imminent or inevitable EU collapse
- assigning a point probability of union failure by 2035
- treating every missing feature of a mature federation as automatically load-bearing for minimal union durability
- collapsing `durable equilibrium`, `fragile but intact`, and `material union failure` into one undifferentiated outcome

## End States

### Success

The project cleanly distinguishes:

- `durable_equilibrium`
- `fragile_but_intact`
- `material_union_failure`

and identifies which missing pillars are most plausibly load-bearing now, while keeping any 2035 forecast claim bounded to a directional tilt rather than a false-precision percentage.

### Failure

The project drifts into any of the following:

- a single narrow mechanism project presented as if it answers the whole union-durability question
- a collapse forecast without explicit event boundaries
- a laundry-list thesis with no pillar ranking
- a purely rhetorical argument with no independent discriminator between the end states
