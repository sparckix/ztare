# LLM Forecast Calibration Paper Mirror

This directory is the lean paper mirror for the forecasting-calibration paper.
Working files, build artifacts, legacy PDFs, and submission packaging live in
the root project directory:

`llm-forecast-calibration-cross-corpus/`

## Contents

- `main.tex`: public/plain LaTeX manuscript.
- `refs.bib`: bibliography.
- `draft.md`: Markdown manuscript copy with the same submission abstract.
- `main.pdf`: rendered PDF.
- `evidence/`: curated claim evidence, figures, figure reproducer, and the
  forecast-row validity benchmark validator.

Do not put scratch work or submission packaging here.
