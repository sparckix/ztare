# Governed adversarial evaluator hardening

Public source for the merged paper *Governed adversarial evaluator hardening: mined-constraint mechanisms and contract-gated recursive improvement*. It combines and supersedes two earlier manuscripts: Adversarial Precedent Memory (the hardening mechanisms and benchmark) and Contract-Governed Hardening (the deterministic governance of recursive improvement). The two earlier root directories are retained under `provenance/` in the private working root.

Files: `draft.md` (canonical text), `main.tex` / `main.pdf` (XeLaTeX-free pdflatex build), `paper2_figure1.png` and `paper2_figure2.png` (primitive schema, recursive-hardening loop), `refs.bib`.
