# When Consciousness Cannot Be Identified

**A Descent-Theoretic Framework for Scientific Admissibility**

This manuscript argues that consciousness attribution requires an identification claim: the target property must be recoverable from the declared evidential site. It develops a formal admissibility criterion for cases where that recovery fails, and applies the criterion to consciousness theories and AI-system disclosure.
