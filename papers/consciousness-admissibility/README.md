# Consciousness Admissibility

Public mirror for:

**When Consciousness Cannot Be Identified: A Descent-Theoretic Framework for Scientific Admissibility**

The manuscript argues that consciousness attribution is partly an identification problem: a verdict is scientifically licensed only when the target property is recoverable from the declared evidential site. The paper is primarily philosophy of science and philosophy of mind, with formal-methods apparatus used to make the admissibility criterion precise.

- `main.pdf`: rendered manuscript
- `refs.bib`: bibliography
