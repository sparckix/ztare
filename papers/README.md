# Papers

Tracked public paper bundles live here.

This directory is the public-facing paper layer, not the full construction site. It keeps the manuscript sources readable without dragging along every local build workspace, supervisor artifact, or drafting scratch file.

- `paper1/` — **Cognitive Camouflage**: specification gaming in LLM-generated code | [SSRN](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=6512960)
- `paper2/` — **Adversarial Precedent Memory**: hardening evaluators through mined failure constraints | [SSRN](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=6525598)
- `paper3/` — **Contract-Governed Hardening**: stage-gated recursive improvement with typed promotion contracts | [SSRN](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=6542998)
- `paper4/` — **Cognitive Firm**: managerial capitalism for artificial intelligence | [SSRN](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=6543019)
- `paper5/` — **Epistemic Verification** | draft / active public bundle.
- `paper6_neural_scaling/` — **Neural Scaling** | draft / active research manuscript; claims remain scoped by the experiment ledger.
- `paper7/` — **Discovery Case Studies** | draft / active research manuscript; claims remain scoped by the experiment ledger.
- `experimental_math_letter/` — **Adversarial Compression** | draft / auxiliary experimental-math manuscript.
- `case_studies/` — small public case-study notes | supporting material, not standalone papers.

Public bundles contain only the files needed for GitHub browsing and source reuse.

In general that means:

- `draft.md` — canonical markdown manuscript
- `main.tex` / `refs.bib` — LaTeX source
- `main.pdf` — rendered public mirror PDF when available
- paper-specific figures or evidence bundles when a paper makes auditable artifact claims

Root directories such as `paper1/`, `paper2/`, `paper3/`, and `paper4/` are local scratch/build workspaces and are gitignored.
