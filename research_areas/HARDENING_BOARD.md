## Status Legend

- `active`: currently open and should shape near-term engineering decisions
- `verify`: implementation exists; run the verifier or live test before closing
- `blocked`: seam is known but should not be worked until another seam closes
- `done`: closed and should remain here only for recent memory / provenance
- `frozen`: intentionally parked with a specific reopen condition

## Operating Rule

When a new issue appears:

1. Decide whether it is project-local or generic.
2. If generic, add a board card here immediately.
3. If it becomes bounded and implementation-ready, promote it into a seed or program.
4. If it closes, move it to `done` with one line of provenance rather than deleting it.

The point of this board is to stop losing the hardening thread across projects and reruns.
