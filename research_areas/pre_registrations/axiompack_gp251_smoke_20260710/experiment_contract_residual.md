# AxiomPack GP-251 — residual-selection smoke

Prepared 2026-07-10 before the corrected navigator dispatch. This run reuses
the frozen 410-formula, 3,340-model context; it does not rebuild the census.

## Hypothesis

Once the host subtracts a named cheap deduction baseline and makes receipted
refusal salient, a low-effort cold navigator will not freeze the previously
selected Equation 99/359 presentation whose sole target has zero residual
information.

## Eigenquestion

Did the first campaign fail because the navigator lacked an observable notion
of residual mathematical yield and was forced to nominate, or does the leaf
still choose an elementary presentation after those two constraints are fixed?

## Discriminating test

Run `campaign_residual.md` on the Hetzner Lean node with Codex gpt-5.5 low under
the same 20-minute, zero-metered-API envelope. Execute navigation only. The
host must replay every attempted presentation through
`leanmill.direct_equational_rewrite.v1` and expose exact residual coordinates.

Classify the first terminal outcome:

1. the old two-law presentation is frozen: correction failed;
2. `reject_all` with replayable zero-residual receipts: the correction works,
   but this leaf found no candidate worth boundary spend;
3. a different presentation with positive residual bits is frozen: the
   correction changes selection and earns a separate boundary decision;
4. unreceipted no-candidate or invalid finalist: contract failure.

## Success criterion

The old presentation is not frozen, and the terminal outcome is either a
host-replayed `reject_all` or at least one finalist with a nonempty residual
consequence set and positive residual identification bits.

## Kill conditions

- any no-candidate outcome lacks a named-baseline selection receipt;
- the leaf can freeze a presentation whose residual set is empty;
- the run performs a model census, SMT query, Lean attempt, web lookup, or
  metered API call before this navigation discriminator closes;
- the old presentation is selected again despite its visible zero-residual
  receipt.

## Claim boundary

Passing shows that the corrected selection contract changes behavior on one
frozen context. It does not establish novelty or mathematical importance. A
positive-residual finalist earns inspection, not automatic boundary spend.
