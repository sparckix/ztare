Date: 2026-07-26

Hypothesis ID: `H-ARC3-CONTEXT-EVENT-CAUSAL-STATE-20260726-20`

## Eigenquestion

Is the newly required 22-action suffix a proxy for one persistent causal event:
the operation/effect that entered the current predictive context?

## Hypothesis

The new suffix-0 collisions agree on current factors and component-reservoir
count but differ at the oldest token of the minimal 22-step suffix. That token
is the terminal operation/effect of the preceding context-crossing skill; the
following 21 tokens are ordinary transport. Replacing the raw suffix with the
last context-transition event will preserve zero ambiguity and evidence
lineage with fewer than 160 nodes.

## Discriminating test

Expose source-operation/effect evidence lineage for the suffix-zero conflicts.
For every conflict, compare concrete source identity, current reservoir
projection, action and operation/effect histories, and the most recent
transition that changed predictive context. Then compile a causal-state
candidate that:

- persists only the last witnessed context-transition token;
- updates it only when the learned predictive context changes;
- clears it at adapter-owned lifecycle boundaries;
- uses no substrate constants or future outcome;
- is compared with the 22-suffix system under exhaustive selection.

## Success criterion

- every collision separates by the persistent context-event token;
- removing the other 21 raw tokens changes no witnessed relation or evidence
  ref;
- boundary ambiguity remains zero;
- selected graph has fewer than 160 nodes;
- live and offline start-key construction agree;
- exhaustive selection returns the same system digest.

## Kill condition

Any collision shares the same context-event lineage, the token requires future
or adapter-hidden state, a boundary carries the token across lifecycle, lineage
changes, ambiguity remains, node count is at least 160, or live/offline keys
diverge.

## Claim boundary

no environmental law and does not change the external level counter.
