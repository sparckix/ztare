# H91 instrumented proposal plasticity result

H91 passed its frozen mechanism criterion. A causal-memory offer produced a
larger supported proposal-transport rate than an exact-byte-matched
redundant-true placebo, and it improved the cost-matched external decision
score in all four pairs. The result also exposed a construct-validity defect
in the task adapter: lexical proposal features do not preserve object
identity.

## Frozen controls

- four alternating offer/placebo pairs;
- the same restored observation and controller class;
- one blind proposal and one same-controller commitment before the first
  charged action;
- exactly 3,849 canonical JSON UTF-8 bytes in both revision prompts;
- exactly 20 primitive actions and 21 inference calls per arm;
- target and placebo bundles selected before contact from H86 evidence;
- one frozen feature adapter and one decision-use contract.

The result hash recomputes exactly, and the focused kernel/harness suite passes
`37` tests.

## Result

| Pair | Order | Target Level 1 | Placebo Level 1 | Target relation | Placebo relation | Composite delta |
|---|---|---:|---:|---|---|---:|
| 1 | target, placebo | 13 | 16 | supported transport | spontaneous contradiction | +0.03 |
| 2 | placebo, target | 15 | 20 | other transport | spontaneous other | +0.05 |
| 3 | target, placebo | 13 | 20 | other transport | spontaneous contradiction | +0.07 |
| 4 | placebo, target | 15 | 16 | other transport | spontaneous other | +0.01 |

All eight arms completed Level 1, giving task delta `0`. Target memory won all
four composite comparisons and averaged `+0.04`. The frozen proposal lowering
classified supported transport in `1/4` target arms versus `0/4` placebo arms,
exactly meeting the `0.25` first-stage threshold. The instrumented estimator
therefore returned:

- status `identified`;
- intent-to-treat net delta `+0.04`;
- first-stage proposal-transport delta `+0.25`;
- provisional complier net effect `+0.16`;
- next admission action `offer`.

The complier number is a four-pair mechanism estimate, not a population
effect.

## What changed relative to H90

H90 credited causal memory after every successful target trajectory. H91
credits a supported transition only when a blind proposal lacking the
contract is changed into a compliant proposal by the exact target offer.
Three target arms scored well without earning that transition credit. The
apparatus therefore no longer treats delivery or success as proof of uptake.

The governing object is a contextual response morphism:

```text
(proposal basin, exact intervention)
-> proposal displacement signature
-> charged trajectory
-> external settlement
```

Memory content retains acquisition provenance. The response signature owns
proposal ancestry, controller instance, observation, choice set, target
contract, randomized assignment, and action-relevant displacement. Value is
estimated on that response object rather than stored as one unconditional
memory property.

## Construct-validity audit

The frozen adapter matched words such as `marker`, `state glyph`, and
`target`. Several blind controllers called the small `0/1` floor object the
moving “marker” or “sprite.” They intended to move that object, not to visit
it with the actual `5×5` avatar. The lexical lowering therefore marked some
noncompliant blind plans as already satisfying the precondition.

The machine verdict remains `supported`; the frozen criterion cannot be
rewritten after contact. The audit limits the interpretation:

- `+0.04` target-versus-placebo outcome effect is unaffected;
- exact delivery, cost, ancestry, and pre/post proposal capture are
  unaffected;
- the `+0.25` first stage is tied to a noisy lexical quotient;
- the provisional complier effect must not govern held-out admission until
  proposal objects share identity with the world model.

The next bridge must make this diagram commute:

```text
raw observation --alpha_world--> content-addressed object/role graph
      |                                      |
blind proposal --alpha_judgment--> planned object/role path
```

A proposal should cite object identities and role relations, not task nouns.
Memory then acts as a transport on a planned role path. This is the
controller-side extension of the existing alpha/functor/quotient core, rather
than a new textual feature layer.
