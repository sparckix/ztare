# H111: local viable option fiber

Date: 2026-08-06

Hypothesis:
`H-GPSA-LOCAL-VIABLE-OPTION-FIBER-20260806-111`

Status: pre-registered after H110 settlement and before the bounded cached
environment search

## Trigger

H110 showed that the H96/H109 descendant target is a refusal control: the full
H95 winning option is unsupported there, and the spatially aligned suffix has
a distinct uncredited effect identity. Replaying the H95 option from its exact
source would only calibrate an executor. A positive transfer assay instead
needs a distinct current state on which a remembered motor program retains its
effect and task boundary.

## Eigenquestion

Does a bounded counterfactual neighborhood of the credited H95 route contain
a distinct exact state from which the H95 pre-completion suffix preserves its
factored effect path and reaches the same external level boundary?

## Hypothesis

The successful option occupies a non-singleton local viability fiber. Starting
from the canonical five-action prefix that reaches H95 winning-route index
four, at least one prefix within action Hamming radius two reaches a distinct
exact factor state for which the frozen eight-action suffix
`0,0,3,3,3,0,0,0` has the same ordered mechanism-effect signature and gains a
level.

## Discriminating test

Using the content-addressed cached `ls20` environment, fixed seed `0`, and no
controller call:

1. verify that prefix `2,2,2,0,0` reproduces H95 route index four exactly;
2. enumerate every length-five prefix at Hamming distance zero, one, or two
   from that prefix (`106` candidates before exact-state quotienting);
3. from each settled source, execute the frozen eight-action H95 suffix;
4. record exact observation, factor identity, ordered mechanism-effect
   signature, level boundary, primitive contact count, and duplicate source
   multiplicity;
5. require a candidate distinct in exact grid and factor identity from the
   canonical source, not merely a different history reaching the same state;
6. replay the H109 seven-action prefix as a frozen refusal control;
7. mutate one source grid hash, one factor coordinate, one suffix operation,
   and one environment-source identity in receipt-only negative fixtures.

The search may identify a later live target but grants no task credit and
performs no controller fork.

## Success criterion

Stage A is supported only if:

- the canonical prefix and suffix reproduce the H95 source, effect signature,
  and level gain;
- at least one distinct exact factor state within radius two preserves that
  full ordered effect signature and level boundary;
- the H109 refusal control fails either effect equivalence or level gain;
- duplicate histories are quotiented by exact state rather than counted as
  transfer targets;
- all identity/word mutation fixtures are detected; and
- primitive environment contacts are reported without being converted into
  model-call or skill credit.

## Kill and refinement rule

Reject the local-fiber hypothesis if only the canonical exact state succeeds,
if successful alternatives change the mechanism-effect signature, if the
H109 control is admitted, or if any identity mutation crosses the receipt
boundary. A rejection means the present evidence contains no local positive
transfer target for this option. The next acquisition must deliberately
generate viable state variation before another memory/controller comparison.

## Claim boundary

Passing would identify one candidate transfer state in one bounded local
neighborhood. It would not establish option task credit at that state, live
controller benefit, cross-task transfer, benchmark gain, catalytic learning,
criticality, capability takeoff, or literature novelty.
