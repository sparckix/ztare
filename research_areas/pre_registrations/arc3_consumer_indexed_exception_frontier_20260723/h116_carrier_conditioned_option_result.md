## Interpretation

Historical skill memory can nominate a compressed operation word; the accepted
forward carrier can lower that word into a current-state-specific effect path;
environment execution can settle the prediction. Neither exact replay nor
statistical interpolation is required.

This is a concrete architectural payoff from the alpha/functor/quotient core:
the motor word is invariant, endpoint and effect are reindexed over the current
state, predictive provenance remains distinct from observed settlement, and a
failed carrier step can refuse. The missing connection was between the skill
compiler and the carrier already used by factored search.

The next implementation boundary is narrow: create a carrier-conditioned
option prediction/settlement object, then allow the planner to request it only
when an exact historical guard is unwitnessed. Promotion still requires
externally settled effect and, separately, task credit.
