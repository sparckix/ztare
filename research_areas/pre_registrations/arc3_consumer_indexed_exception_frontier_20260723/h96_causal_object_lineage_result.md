## Temporal counterexample

The source H95 contract required:

```text
controlled object = moving occurrence
future waypoint   = marker occurrence
```

H96 transported those roles unchanged to a descendant reached only after
marker contact, marker occlusion, glyph revision, and departure. At that
descendant, the successful causal proposal controlled the moving occurrence
but omitted the already-visited marker from its future waypoints. It therefore
failed the static contract while completing the level at the same action
index as H95's causal arms.

The failed invariant was the literal future path. The prefix had consumed
part of the response contract, but transport treated the contract as
time-independent.

## Architectural consequence

A response contract must support a receipt-backed temporal derivative. Given a
source response language `C` and a certified transition prefix `h`, the
descendant authority should be the residual `D_h(C)`: future obligations after
the events in `h` have discharged completed subgoals.

This suggests a stricter continual object:

```text
source response family
    + causal occurrence lineage
    + transition-event word
    + residual-contract derivative
    -> exploratory descendant admission
    -> randomized descendant settlement
    -> descendant response credit
```

The derivative must be computed before descendant outcome. Ambiguous event
binding, proxy event families, or an unrecognized transition symbol refuse.
External success cannot retroactively choose the residual.

## Critical-mass consequence

Let `K[i,j]` be the expected number of independently settled, admissible
children in response family `j` produced by one settled response in family
`i`, after intervention and primitive-action cost. The response system is
subcritical while the spectral radius `rho(K) <= 1`; it crosses the proposed
critical-mass boundary only when `rho(K) > 1` with bounded false transport.

H95 produced one parent family. H96 produced no promoted child, so the strict
observed offspring count remains `0` despite the positive behavioral effect.
The failure factor is consolidation under temporal residualization.

## Prior-art boundary

Reward machines, temporal-logic progression, automaton task state,
eligibility traces, object permanence, and causal tracking are established.
The candidate research surface is narrower: learn a response from randomized
external settlement; bind its object occurrences through exact environment
lineage; derive its remaining obligations from the certified event prefix;
use that residual as pre-outcome admission and credit authority; then measure
whether settled children make the response reproduction operator
supercritical. H96 does not establish that joined mechanism.

## Claim boundary

H96 supplies one positive behavioral pair and two identity counterexamples.
It does not identify a descendant response, establish a causal contract
derivative, show response reproduction, demonstrate accelerating gains, improve
an ARC benchmark score, or establish literature novelty.
