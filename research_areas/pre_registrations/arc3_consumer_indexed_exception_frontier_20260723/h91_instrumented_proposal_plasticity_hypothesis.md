# H91 instrumented proposal plasticity hypothesis

## Eigenquestion

Did H90 fail because causal memory has unstable value, or because the system
treated an offered memory as though it had necessarily changed the
controller's active proposal?

## Hypothesis

The useful object is a contract-relative proposal transport, not a scalar
attached to memory content.  At the same task, observation, controller class,
choice set, and action vocabulary, offering causal mechanics should increase
the probability that a blind proposal which lacks the state precondition is
revised into one that includes it.  A byte-matched redundant-true placebo
should reveal spontaneous revision under the same two-inference protocol.

The randomized offer is an instrument; verified supported proposal transport
is endogenous uptake; externally observed task and efficiency score is the
settlement.  The predicted first-stage transport delta is at least `+0.25`.
The target intervention must have nonnegative total task delta and positive
mean `0.8 task + 0.2 efficiency` intent-to-treat delta after the equal
presentation cost.

## Discriminating test

Run four alternating matched pairs from the same restored observation.  Every
fresh Sol `xhigh` controller first emits a blind, uncharged proposal with an
action, visible prediction, plan summary, and uncertainty.  Before the
environment advances, random assignment supplies either:

- the evidence-selected causal-mechanics bundle; or
- the exact-byte-matched redundant-true placebo bundle.

The same controller then emits a committed proposal and spends exactly 20
charged actions.  A frozen external adapter lowers pre/post proposal text to
the contract features `state_precondition_first` and
`terminal_before_precondition`.  The common kernel binds proposal ancestry,
controller instance, observation, contract, assignment, intervention,
response signature, and external outcome.

The estimator reports the offer-minus-placebo first stage, reduced-form
cost-adjusted outcome delta, and a complier effect only if the first stage is
at least `0.25`.

## Kill conditions

Reject the proposed mechanism if identities drift; rendered bytes, proposal
inference count, or primitive action cost differ; the first stage is below
`0.25`; the target intervention loses total task score; or mean composite
intent-to-treat delta is nonpositive.  A weak first stage forbids laundering
the outcome association into uptake credit.

## Prior-art inversion

Closest public systems already cover causal memory selection, counterfactual
agent replay, or process attribution:

- Causal Intervention-Based Memory Selection:
  <https://arxiv.org/abs/2605.17641>
- Causal Agent Replay:
  <https://arxiv.org/abs/2606.08275>
- AttriMem:
  <https://arxiv.org/abs/2607.21106>
- RICE-PO:
  <https://arxiv.org/abs/2605.26352>

H91 does not claim novelty for retrieval intervention, counterfactual replay,
or local attribution.  The candidate contribution is the combination of
blind proposal lineage, randomized memory encouragement, explicit
offer-versus-uptake separation, a quotient of action-relevant controller
response, weak-instrument refusal, external settlement, and conditional
replay of response signatures.  The claim remains provisional until the live
discriminator passes and a broader source comparison finds no equivalent
construction.
