# H102 witnessed protocol response readout

Date: 2026-08-07

Hypothesis:
`H-GPSA-WITNESSED-PROTOCOL-RESPONSE-READOUT-20260807-102`

Status: pre-registered; controller-neutral and offline

## Eigenquestion

Can one evidence-owned post-intervention partial-action observation be lowered
into exactly the response object forecast by a selected witnessed protocol,
so H101 can measure realized information yield without consulting task status?

## Hypothesis

A selected witnessed protocol freezes a preparation target, probe operation,
response committee, and continuation-readout operation set. Given an observed
source key equal to that target, the exact probe operation, and either:

- an ordinary witnessed effect plus successor key; or
- an authority-owned boundary kind,

the post-intervention response can be reconstructed by adding that observation
to the frozen partial relation and applying the same response compiler used for
the committee. Existing relation effects and targets are unioned rather than
overwritten. H101 may then measure the realized response cell.

## Discriminating test

1. Build a witnessed partial action system containing three analogous probe
   sources whose response partition has cell sizes `(2, 1)`.
2. Select a novel target/probe protocol and freeze its H101 forecast.
3. Supply an ordinary observation whose effect and successor continuation
   match the size-two response class. Verify that the reconstructed response
   hash equals that class and H101 reports its frozen posterior reduction.
4. Supply a different witnessed effect and verify committee refutation.
5. Supply an authority-owned boundary and verify a typed boundary response.
6. Change only observed source or operation and verify refusal.
7. Compare the direct single-observation reconstruction against recompiling
   the augmented partial action system and applying the existing response
   compiler.

## Success criterion

1. Direct and augmented-system response objects are identical.
2. A known response selects the correct frozen committee cell and realized
   yield.
3. A new effect reports committee refutation.
4. A boundary remains typed and is not represented as an ordinary successor.
5. Source or probe mismatch is refused.
6. Observation evidence is required.
7. No task or level status enters the response or yield receipt.
8. Protocol costs remain unchanged.

## Kill conditions

- the direct readout differs from augmented relation recompilation;
- source or operation mismatch is accepted;
- a boundary is collapsed into an ordinary effect;
- existing relation evidence is overwritten;
- an unseen response is forced into a known cell;
- observation evidence is absent; or
- task status affects the readout.

## Claim boundary

Passing establishes a common response readout from an abstract partial-action
observation. It does not establish extraction of that observation from an ARC
grid transition, automatic play-loop attachment, sealed live replay arms, H97
support, or score gain.
