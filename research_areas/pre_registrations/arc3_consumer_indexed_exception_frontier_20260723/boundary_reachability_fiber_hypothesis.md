## Eigenquestion

Can the acquisition learner preserve action-chunk identity and concentrate
experiments on task-relevant reachability when its observational quotient
refines, without completing the growing pairwise support relation?

## Proposed object and transport

Use the accepted consumer factorization as the control base. Keep four
identities separate:

1. a control node is the complete consumer state needed for transition
   consequences;
2. support is the set of witnessed operations over that node;
3. an option is an operation program plus its concrete initiation lineage,
   independent of any mutable quotient-class identifier;
4. task completion is an external boundary map and is never inferred from a
   control node.

The projection's existing acquisition key supplies the context fiber. A
change in that key is a context transition. Adapter-attested lifecycle edges
remain typed boundaries. Exceptional-effect scores rank edges within the
reachable graph; they do not define state equality.

## Discriminating test

Compile a substrate-agnostic boundary-reachability fiber system from the
current witnessed partial action system. Import the six option programs from
the pre-refinement predictive-quotient receipt by their concrete initiation
member digests and operation words, then reindex them through the current
graph.

Measure:

- section and edge transport from concrete witnesses;
- reachable control nodes and source-operation frontier;
- context-transition and typed-boundary edges;
- each imported option's current initiation fibers, terminations, and
  context-gating status;
- the highest-ranked reachable frontier whose path crosses or approaches a
  context transition or typed boundary.

No live action is part of this test.

## Predictions

- All six learned operation programs remain represented after quotient
  refinement. A program may split into context-gated outcomes or become
  partially unsupported, but it does not disappear because a class ID
  changed.
- The graph-level reachable frontier is much smaller than the pairwise
  compatibility-gap surface and does not grow quadratically with source
  count.
- At least one witnessed context transition or typed boundary supplies a
  reachability-critical edge, allowing experiment rank to prefer a
  boundary-adjacent or post-transition frontier over the next global support
  gap.

## Kill conditions

- a program can be recovered only by importing its old quotient class as
  present state identity;
- a recovered program borrows an unwitnessed edge or invents a successor;
- concrete section or edge transport fails;
- no context-transition or typed-boundary structure is reachable from the
  active start;
- the proposed rank reduces to global support completion;
- any substrate coordinate or game rule enters the common compiler.
