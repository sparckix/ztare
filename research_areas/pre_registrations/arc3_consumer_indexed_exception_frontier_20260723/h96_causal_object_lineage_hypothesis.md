# H96 causal-object-lineage hypothesis

## Eigenquestion

Can H95's newly promoted response survive the state change it helps produce,
when appearance types split but environment-receipt ancestry remains unique?

## Hypothesis

Static object types are appearance identities. A response contract that cites
only those identities loses its objects when the actor occludes a marker or an
interaction revises a glyph. A receipt-carrying lineage quotient can preserve
the governing carrier without weakening appearance identity.

Along the frozen descendant path from H95's source observation, the compiler
should track four required object files through unique exact-type continuation,
one fixed-support appearance revision, and bracketed one-frame occlusion. The
resulting lineage transport should move the H95 response contract and witness
to the descendant observation even though static unique-type transport
refuses.

If a fresh blind descendant proposal occupies the transported response basin,
the circuit should mark causal memory `explore_lineage` before delivery.
Randomized descendant settlement should determine whether that second-
generation response earns a new family.

## Discriminating test

1. Verify the frozen H95 result, manifest, promoted family, response, target
   contract, and pre/post proposal witness.
2. Replay `[2,2,2,0,0,0,1]`; require the frozen source observation at index
   one and frozen descendant observation at index seven.
3. Reproduce the static-type failure: direct transport binds only `3/4`
   required objects and the sequential path first refuses on transition
   `5 -> 6`.
4. Compile appearance lineages from ordered catalogs and environment
   transition receipts only. Permit exactly four relation types: unique exact
   type, unique fixed-support appearance revision, bracketed occlusion entry,
   and unique reappearance exit.
5. Require all four lineages to resolve uniquely at the endpoint. Bind the
   target contract to the target-scoped intervention revision and the lineage
   receipt.
6. Before delivery, require each blind target and placebo proposal to occupy
   the lineage-transported H95 basin. The causal action is exploratory; no H96
   outcome may enter admission.
7. Run two alternating causal/placebo pairs with the exact seven-action
   prefix, 3,849 intervention bytes, two proposal calls, and 20 post-prefix
   actions per arm.
8. Promote a descendant response only after randomized target-fiber
   settlement passes.

## Success criterion

Static type transport refuses; lineage transport resolves `4/4` with at least
one appearance revision and one bracketed occlusion; all four blind proposals
occupy the transported basin; causal supported transport is `2/2`; placebo
spontaneous support is `0/2`; first stage is `1.0`; causal memory has
nonnegative task delta, positive mean composite delta, and at least one win;
all source, ancestry, and cost checks pass.

## Kill conditions

Kill on source/path drift, a complete static-type map, an ambiguous lineage
successor, unbracketed absence, changed fixed support, forbidden semantic
input, a noncommuting target response square, blind-basin mismatch,
post-delivery admission, uptake failure, spontaneous placebo support, cost
drift, task loss, nonpositive mean delta, or zero wins.

## Prior-art boundary

Object permanence, occlusion tracking, slot alignment, object transition
models, structured object/skill memories, and provenance DAGs are established.
H96's candidate contribution is the joined mechanism: exact transition-receipt
lineage becomes necessary authority for a randomized response, acts
prospectively, and earns descendant credit only from a new external
counterfactual. Passing does not by itself establish literature novelty.

## Claim boundary

H96 tests one second-generation response along one six-transition descendant
path. It does not establish arbitrary object permanence, repeated
multi-generation compounding, cross-task transfer, accelerating gains, ARC
benchmark improvement, or literature novelty.
