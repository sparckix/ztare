# H94 prospective response-family admission hypothesis

## Eigenquestion

Does the H93 object-path eligibility trace improve a later intervention choice,
or is it only a better retrospective description of forced recall?

## Hypothesis

A response family grouped by exact blind proposal basin can transport H93's
externally settled causal credit to new stochastic controllers. Before any H94
outcome exists, the family should recognize the H93 wrong-control basin and
select causal mechanics. H90's final scalar credit state, which lacks proposal
state, should select redundant true memory.

Across two fresh alternating-order pairs, the response policy must have
nonnegative total task delta, positive mean paired composite delta, and at
least one composite win over the scalar policy.

## Discriminating test

Rehydrate H93 from its frozen result and arm receipts. Group randomized
offer/withhold outcomes only when scope, object-path contract, intervention,
and pre-basin identities agree. Compile a family only with at least two target
and two placebo outcomes, first stage `1.0`, and positive net
intent-to-treat effect.

For each new policy arm:

1. emit and persist a blind catalog-handle proposal;
2. resolve it to an exact object path;
3. compile the admission decision from the frozen response family;
4. require `offer` from an exact trained basin;
5. only then authorize and inject causal memory;
6. persist the revised proposal, exact transport, and 20-action outcome.

For each scalar-comparator arm, perform the same blind proposal protocol, then
run the existing allocator from H90's exact final credit state over the two
memory proposals. It must select redundant true memory before injection.

Both policies use 3,849 rendered bytes, two proposal calls, one session, and 20
primitive actions. H94 outcomes cannot update either selector until all
selections are frozen.

## Pre-contact apparatus correction

The first launch stopped before controller inference and primitive action
because the H94 spec had replaced the H93 contract's H92 evidence reference
with the H93 result reference. Evidence ancestry belongs to contract identity,
so the family correctly refused the changed contract. The frozen H93 contract
has been restored; H93 training identity remains separate in the response
family receipt.

A second pre-contact launch caught a harness access error in the H90 identity
check: the rehydrated state exposes its canonical SHA-256 through
`to_receipt()`. The check was corrected without controller inference or
primitive action.

## Kill conditions

Kill on any source or family hash drift; selection by condition name or memory
text; unseen/weak response basin; post-delivery admission; comparator drift;
cost mismatch; target policy task loss; nonpositive mean composite delta; or
zero target-policy pair wins.

## Claim boundary

H94 tests prospective reuse of one local response family against a scalar
outcome policy on new controllers. Even a pass leaves cross-basin silence,
cross-context transfer, chained decisions, and accelerating improvement open.
