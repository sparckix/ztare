# H97 causal-response-derivative hypothesis

## Eigenquestion

Can a settled response reproduce once when its descendant authority consumes
completed subgoals and the causal/placebo continuations share one exact blind
controller state?

## Hypothesis

H96 transported a future-waypoint contract unchanged across the event that
fulfilled the waypoint. The successful descendant behavior consequently
looked out of family.

Two randomized H95 causal witnesses share an ordered response program:

```text
control moving occurrence -> marker occurrence -> target glyph
```

The certified H96 transition prefix contains a joint event: the marker enters
a bracketed occlusion and reappears on the next hop while another tracked
object undergoes a fixed-support appearance revision on the same environment
transition. This event is available before the descendant proposal and
outcome. A Brzozowski-style derivative should consume the marker obligation
and produce the residual:

```text
control descendant of moving occurrence -> descendant of target glyph
```

That residual should classify H96's successful causal post-proposal as a
supported response and its placebo as already satisfied rather than
spontaneous support.

A fresh live pair still needs a shared blind state. H97 will create one stored
Responses API parent proposal, then make the causal and placebo revisions cite
the same `previous_response_id`. Only matched, residual-unsatisfied parents may
enter the environment. This makes the memory assignment the branch
intervention while preserving controller reasoning state.

## Discriminating test

1. Hash-check the H95 response family and both randomized supported causal
   witnesses.
2. Infer their common response program by unique common controlled object and
   unique longest common ordered waypoint subsequence.
3. Compile the H96 source-to-descendant event word from object-lineage and
   environment transition receipts. H96 outcomes and target proposals are
   forbidden inputs.
4. Consume a waypoint only under the frozen joint-event rule: bracketed
   occlusion, next-hop unique reappearance, and a different tracked object's
   fixed-support appearance revision on the same transition.
5. Require the expected one-waypoint residual and at least three negative
   refusals: missing co-event, ambiguous lineage/event, and post-outcome or
   proxy event binding.
6. Reclassify the already-observed H96 pair as a construction check. This does
   not count as fresh evidence.
7. For each of two fresh pairs, obtain a blind `gpt-5.6-sol` proposal with
   `reasoning.context=all_turns` and `store=true`. If it already satisfies the
   residual, record and skip it before environment contact, up to four parent
   attempts.
8. Fork each eligible parent into causal and placebo revisions using the exact
   same `previous_response_id`, repeated instructions, identical observation,
   catalog, action set, and byte-matched intervention cost.
9. Admit causal exploration before revision. Run both branch children from
   independently restored copies of the exact seven-action environment prefix
   for 20 charged actions.
10. Promote one descendant child only after the two matched pairs settle.
    Record parent offspring count before and after H97.

## Success criterion

The source program has support `2` and waypoint length `2`; the derivative
discharges exactly one waypoint and leaves one; all negative derivatives
refuse; two eligible pairs share exact parent response and blind-proposal
identity; causal derivative support is `2/2`; placebo spontaneous support is
`0/2`; first stage is `1.0`; task delta is nonnegative; mean paired composite
delta is positive with at least one win; settlement promotes exactly one
child; observed parent offspring count rises from `0` to `1`.

## Critical-mass criterion

Let `R_response` be independently settled admissible children per settled
parent under the same causal response schema, after false-transfer and action
cost. H97 can move the observed count from `0` to `1`, the critical boundary.
It cannot establish `R_response > 1`. A later sibling-fiber experiment is
required for the supercritical claim.

## Kill conditions

Kill on source/program ambiguity, event selection using H96 outcome or target
post-proposal, missing or ambiguous joint-event acceptance, branch parent
identity mismatch, blind-proposal mismatch, effective reasoning context drift,
failure to obtain two eligible parents within the frozen attempt budget, late
admission, causal uptake miss, placebo spontaneous support, cost drift, task
loss, nonpositive mean delta, zero wins, or no promoted child.

## Prior-art boundary

Formal-language derivatives, reward machines, temporal-logic progression,
options, eligibility traces, object tracking, and stored model continuations
are established. H97 tests their narrower joined use as a response
reproduction circuit: induce a program only from randomized externally
settled responses; bind its event word through exact environment/object
lineage; use the pre-outcome derivative as admission and credit authority;
fork one exact hidden controller state; settle the children externally; and
measure offspring. Passing does not establish literature novelty.

## Claim boundary

H97 covers one source family, one descendant, two matched pairs, and at most
one promoted child. It does not establish a supercritical population,
multi-level or cross-task transfer, accelerating gains, benchmark improvement,
or literature novelty.
