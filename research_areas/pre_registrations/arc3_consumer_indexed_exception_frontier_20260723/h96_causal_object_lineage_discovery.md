## Brain analogy compiled into an operator

The useful analogy is an object file with efference-linked ancestry:

```text
appearance occurrence
    --environment transition receipt-->
latent lineage token
    --unique reappearance / fixed-anchor revision-->
new appearance occurrence
```

The lineage is not an embedding and not an inferred role name. It is a partial
quotient over time-indexed appearances. A lift exists only when each transition
has one structurally admissible successor:

- unique exact-type continuation;
- unique fixed-support appearance revision;
- bracketed one-frame occlusion followed by unique reappearance.

Ambiguous successors, unbracketed absence, changed fixed support, or missing
transition evidence refuse.
