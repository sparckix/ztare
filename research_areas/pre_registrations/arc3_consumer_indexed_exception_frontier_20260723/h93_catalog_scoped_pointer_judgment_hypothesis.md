# H93 catalog-scoped pointer judgment hypothesis

## Eigenquestion

Did H92 fail because object-linked policy state is unusable, or because it
forced the controller to reproduce evidence identities instead of addressing
them through a local presentation coordinate?

## Hypothesis

Separating exact object identity from controller-facing presentation will
remove H92's copy channel without weakening the authority boundary. A
deterministic role-free handle map (`o00`, `o01`, …), bound to the exact
observation and catalog digest, should let every proposal resolve to the same
content-addressed objects. On two new alternating-order pairs, causal recall
should produce supported object-path transport in `2/2` target arms; placebo
should produce it in `0/2`.

Target task delta must be nonnegative and mean paired composite delta must be
positive. H92's two completed pairs are excluded from the H93 estimate.

## Brain and architecture analogy

A durable memory trace and the transient pointer that recruits it have
different identities. Connectivity and sparse assemblies address a remembered
object locally; cognition does not serialize the trace's full physical
fingerprint. The software analogue is:

```text
catalog identity:      object:<sha256>
local presentation:    o03
binding authority:     presentation_sha256
controller output:     o03
kernel input:          object:<sha256>
```

This also matches the existing factored-planning split between a partition and
its presentation assignment. `alpha_judgment` must preserve both, resolving
the presentation before it compares paths or assigns credit.

## Discriminating test

Compile the unchanged H92 object catalog. Sort occurrences deterministically
by bounding box, cell count, and type digest. Assign two-digit handles and hash
the complete ordered mapping with the observation and catalog identities. The
actor sees handles plus geometry and shape, without exact object refs or role
labels.

Persist blind and revised handle proposals immediately after each model call,
before resolution. The adapter resolves handles under the exact presentation
digest and constructs the same `ObjectLinkedControllerProposal` used in H92.
The common kernel then applies the unchanged path contract and instrumented
outcome estimator.

Run two fresh alternating-order target/placebo pairs with the same two
proposal calls, 3,849 presented memory bytes, and 20 charged actions per arm.

## Kill conditions

Kill if the presentation map fails one-to-one round trip; any raw proposal is
not checkpointed; a handle is unknown or crosses presentation authority;
handles encode roles; either target arm lacks supported transport; either
placebo arm has spontaneous supported transport; target task score is lower;
or mean composite effect is nonpositive.

## Claim boundary

H93 tests whether a catalog-scoped pointer repairs the controller/worldmodel
identity bridge. It does not test learned silence, cross-context response
families, later-decision improvement, compounding capability, benchmark gain,
or literature novelty.
