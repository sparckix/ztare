**Status:** Passed offline 2026-08-08; live causal refresh remains unsettled.

## Eigenquestion

Can one source-supported relational memory repeatedly re-bind action authority
to the current observation, use the resulting transition to settle its target
transport hypothesis, and continue under a distinct residual-navigation phase?

## Motivation from H128

H128 established delayed compiler consumption but missed its task threshold.
Treatment acquired the registered decision seam in `3/3` arms versus `0/3`

that current-observation replanning selects the oracle action at both failed

disappears instead of moving along the source relation's projected motion cone.

The candidate correction is a lifecycle, not a larger capsule:

1. stable source memory owns the learned palette/D4-quotiented relation;
2. an observation-bound working revision owns exactly one current action;
3. the successor observation scores the target prediction;
4. target disappearance refutes target-motion transport and creates a settled
   residual-navigation revision;
5. stale observation authority cannot cross revisions.

The existing canonical owners must be extended:
`src/ztare/worldmodel/relational_affordance.py` owns scene/frontier extraction,
and `src/ztare/worldmodel/relational_affordance_recall.py` owns recall and
working-memory identity. No parallel memory subsystem is admissible.

## Offline discriminating test

Implement one immutable working-revision chain over each frozen treatment
trajectory. Every revision is bound to the exact current observation, remaining
primitive budget, prior revision, lifecycle phase, and stable source-memory
identity. Before contact it compiles one action from the active relational
frontier. After each transition it emits a prediction-settlement receipt.

At the first transverse target transition, compare the relation-projected
target successor with the observed target successor. The frozen observation
contains no transported target entity. The chain must therefore record
`target_transport_refuted`, preserve the source memory as source evidence, and
enter a distinct `settled_residual_navigation` phase. That phase may plan on
the same learned lattice and goal role but may not claim active target-motion
authority.

Test exact current-scope acceptance, stale-context refusal, predecessor-chain
integrity, source-memory stability, lifecycle transition uniqueness, target
prediction mismatch, residual-route continuation, palette covariance, D4
covariance, and malformed/multiple-target refusal.
