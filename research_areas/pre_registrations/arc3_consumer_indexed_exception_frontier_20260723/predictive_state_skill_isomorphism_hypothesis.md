# H-GPSA-PREDICTIVE-STATE-SKILL-ISOMORPHISM-20260726-44

## Governing identities

- **Learner:** an action-taking system that must compress histories without
  merging histories whose attainable futures differ.
- **Predictive state:** an equivalence class of histories under
  action-conditioned future distributions, not a rendered frame or an
  accumulating tuple of discovered pixels.
- **Skill:** a reusable, temporally extended control operator with initiation,
  termination, expected effect, and failure model over predictive states.
- **Update authority:** offline prediction error and intervention evidence may
  refine the learner; neither may assert environment completion.

## Eigenquestion

Can the observed abstraction failures and biological action learning be
transported into a shared mechanism that determines both when a latent state
must split and when transitions should compile into a reusable skill?

## Left fingerprint: interactive control

The learner's quotient omits latent coordinates. Counterexamples reveal erased
state factors one at a time, while restoring the full product state makes
monolithic route search expand rapidly and still does not identify skill
chunks.

Abstract form: perception induces a predictive state representation;
action-conditioned prediction errors split state only when they alter attainable
futures; repeated transition structure compiles into temporally extended
operators; planning reuses learned controllable equivalence classes.

Required invariants:

- observation aliasing: same current features, different action images
- refinement signal: action-conditioned forward-simulation counterexample
- state decomposition: actor × mutable objects × resource automata × clock
- compression pressure: minimal predictive sufficient state, not full observation
- skill requirement: reusable temporally extended control operator
- search failure: a sound product state still expands monolithic search
- exploration rule: choose actions by expected quotient refinement or skill discrimination
- authority: offline prediction never supplies terminal adjudication

## Right fingerprint: sensorimotor action learning

An animal must infer task state under partial observability, update it from
sensorimotor prediction errors, discover reusable action chunks, and arbitrate
between prospective search and cached control.

Abstract form: latent context or belief state is refined at prediction-error
boundaries; repeated controllable sequences consolidate into options or chunks;
uncertainty directs experiments; hierarchical reuse replaces flat action-tree
search.

Required invariants:

- sensory aliasing: same sensation, different action-conditioned future
- teaching signal: action-conditioned sensorimotor prediction error
- latent state: context or belief state sufficient for control
- memory update: prediction-error or event-boundary gated
- skill unit: chunk or option with initiation, termination, effect, and failure model
- planning: hierarchical reuse rather than flat tree search
- exploration: uncertainty or expected information gain
- failure mode: oversegmentation versus catastrophic aliasing

## Discriminating test

Run the local research-isomorphism primitive in `conjecture` mode with the two
fingerprints, Codex as the only model, typed invariant coverage, and a request
for multiple candidates. The built-in schema must reject candidates lacking
either lowering, predictions on either side, kill conditions on either side, or
minimum prediction specificity.

Surviving candidates then face a second manual gate:

1. the mother structure must be outside both home fields;
2. every invariant must have a transport, not a synonym;
3. predictions must state measurement, intervention, horizon, and expected
   directional outcome;
4. the proposal must distinguish state refinement from skill compilation;
5. it must yield one substrate-neutral apparatus experiment.

## Success and kill conditions

Success requires at least one candidate passing both gates and selecting a
falsifiable engine change. Kill on zero survivors, decorative or one-sided
analogy, missing intervention, replay of the existing factor tuple under a new
name, substrate vocabulary in the shared object, or no apparatus discriminator.

## Claim boundary

Any survivor remains a conjecture. It does not establish a neural mechanism,
solve the current environment, authorize action, or qualify for correspondence
promotion without an independently verified experiment.
