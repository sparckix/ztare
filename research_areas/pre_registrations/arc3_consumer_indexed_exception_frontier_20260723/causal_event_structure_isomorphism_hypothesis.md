# Causal event-structure isomorphism hypothesis

Date: 2026-07-27

Hypothesis ID: `H-GPSA-CAUSAL-EVENT-STRUCTURE-20260727-79`

## Eigenquestion

Did the engine attach task identity to the final transition because it
represented an intervention process as a state path, when the invariant object
is the partial order of outcome-relevant events produced by that process?

## Hypothesis

Successful action learning and sparse-outcome credit assignment share a finite
causal event structure:

- occurrences are observed mechanism changes or typed boundaries;
- dependence means that removing or reordering one occurrence changes the
  admissibility or effect of another;
- independent occurrences commute and their concrete order is coordinate;
- a skill is a reusable guarded substructure with an executable linearization;
- task evidence labels an authority-boundary cut, not its last local edge;
- credit is the backward dependency cone of that cut.

Changing from action strings or local-edge descriptors to this object will
identify an implementable apparatus discriminator that neither increases a raw
history suffix nor names a substrate event.

## Discriminating test

Run Codex-only `research_isomorphism.py --mode conjecture --typed-mapping`
between two frozen, operator-neutral fingerprints:

1. interactive histories with sparse authority outcomes, nuisance transport,
   typed resets, guarded reusable programs, and H78's local-edge collision;
2. goal-directed sensorimotor learning with delayed outcomes, outcome
   devaluation, eligibility/credit assignment, action chunking, and causal
   intervention.

Require transport of carrier, occurrence, dependence, independence,
composition, symmetry, task/outcome, credit, failure, and authority. Reject a
candidate whose shared object is a raw string, fixed suffix, state quotient,
local terminal predicate, graph frontier, reinforcement-learning label, or
substrate vocabulary. Require an executable bounded discriminator in which two
traces differ by commuting nuisance events but have the same task process,
while a trace with the same last edge but a missing causal prerequisite is
different.

Then inspect existing primitives against the selected object. Do not implement
or run an ARC audit under this hypothesis.

## Success criterion

At least one schema-complete candidate:

- defines a mother structure outside both home vocabularies;
- transports all ten required invariants in both directions;
- gives explicit maps from ordered observations to a dependency structure and
  back to an executable guarded linearization;
- predicts invariance to swapping independent events and sensitivity to
  deleting a causal prerequisite;
- localizes sparse outcome credit to a backward cone;
- selects one bounded common-module discriminator not already implemented.

## Kill condition

No candidate survives; the mapping is decorative or one-sided; dependence
requires the future outcome label; task authority is inferred from a boundary
kind; independent-event swaps change identity; deletion of a prerequisite does
not; no executable inverse/linearization exists; or the proposal repeats an
existing suffix, quotient, skill compiler, protocol pricer, or task-edge
contract.

## Claim boundary

A pass selects a common apparatus experiment. It does not establish a
biological account, certify the event dependencies on ARC evidence, authorize
an environment action, or discharge Level 3.
