# H110: viability-conditioned option recall

Date: 2026-08-06

`H-GPSA-VIABILITY-CONDITIONED-OPTION-RECALL-20260806-110`

Status: pre-registered after H109 settlement and before the frozen-history

## Trigger

H109 restored the complete sensorimotor prefix and removed H108's negative
mean, but produced zero action displacement, zero mean effect, zero wins, and
zero children. Retrospective factor comparison found that the H109 controller
followed the spatial skeleton shared by both successful H95 causal arms while
carrying a different finite configuration, one fewer budget unit, and a false
feasibility coordinate at the corresponding route positions. At the H95
pre-completion position, operation `0` completed the level; at the H109
spatially equal position, the same operation was an identity transition.

The full frozen H63 history graph has not yet been queried for whether the
H109 target factor belongs to any witnessed success-predecessor basin. H110
freezes that question before the query.

## Brain-derived conjecture

Episodic replay should propose a sensorimotor option, while the current
affordance/viability circuit decides whether that option can act. Recall does
not receive control authority merely because a semantic response transports
or a spatial path aligns. A remembered option is eligible only when its
initiation state, resource/configuration guard, deterministic effect path, and
externally credited termination remain available in the current factor
fiber.

## Eigenquestion

Did H97--H109 evaluate memory from a target state outside the witnessed
viability domain of the H95 winning option, and can the existing guarded-option
machinery refuse that reuse from state evidence alone?

## Stage A: frozen-history viability discriminator

Using only artifacts frozen before H110:

1. reconstruct the H63 factored history graph and its success boundaries;
2. compile the maximal common pre-completion motor word from the two H95
   successful offers, retaining their exact factor paths and external outcome
   receipts;
3. identify the H96/H109 target factor from the content-addressed seven-action
   prefix;
4. compare controlled position, finite configuration, ordered budget,
   one-shot availability, and ordered feasibility separately;
5. query whether the exact target factor, and each declared coarsening that
   removes one coordinate family, has a witnessed path to a success boundary;
6. reindex the H95 option through the existing boundary-reachability fibers;
7. require exact initiation/effect admission for execution and emit a typed
   refusal otherwise;
8. run negative controls that mutate only position, configuration,
   feasibility, budget, option word, source lineage, or success receipt.

No controller or environment call is permitted in Stage A.

## Success criterion

H110 is supported at Stage A only if:

- both H95 offers induce the same pre-completion motor word and witnessed
  success termination;
- the H109 target matches a tempting spatial projection of that route but
  differs on at least one factor required by the successful transition;
- the exact target has no witnessed success-boundary path in the frozen graph,
  or the H95 option reindexer refuses it at initiation/effect transport;
- at least one declared coarsening would falsely admit the target, showing why
  position-only or semantic-path matching is insufficient;
- every authority and factor mutation is detected; and
- the result changes the live-test policy: nonviable targets are excluded from
  positive skill-transfer assays and counted as refusal tests instead.

## Kill and refinement rule

Reject H110 if the exact target has a witnessed success path compatible with
the H95 option, if no required factor distinguishes it from the successful
route, if refusal depends on outcome leakage, or if an authority/factor
mutation is accepted.

If the target is viable, the next mechanism must be a prospective
action-advantage gate over competing executable options. If it is nonviable,
the next live experiment must select a fresh exact target from the witnessed
viability domain and randomize executable option offer/withhold before the
first divergent action. More advisory-memory text is excluded in both cases.

## Claim boundary

Stage A can identify a state-selection category error and establish a
controller-neutral option-refusal rule on one frozen ARC history graph. It
cannot show global unrecoverability, cross-task transfer, benchmark gain,
compounding, capability takeoff, or literature novelty.
