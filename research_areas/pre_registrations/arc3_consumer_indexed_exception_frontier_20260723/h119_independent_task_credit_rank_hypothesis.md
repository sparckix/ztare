# H119 independent task-credit rank

**Status:** Pre-registered 2026-08-08 before any `tu93` environment action.

## Eigenquestion

Can an unchanged persistent `gpt-5.6-sol` max-effort actor earn an external
level boundary on a distinct ARC-AGI-3 game within 32 primitive actions,
thereby adding an independent task-credited positive episode to the rank-one
skill evidence?

## Frozen intervention

- Game identity: `tu93`; distinct from the credited `ls20` episode.
- Controller: `gpt-5.6-sol`, subscription transport, one resumed session,
  reasoning effort `max`.
- Primitive-action budget: 32.
- Reasoning context: persistent session history supplied by the subscription
  transport.
- Injected task knowledge, learned option, sleep memory, task carrier, and
  cross-game schema: none.
- Boundary sleep: disabled.
- Every raw inference exchange, environment turn, manifest, and final report
  is appended and fsynced to a new H119 trace path before aggregate analysis.

## Prediction and discriminator

Primary prediction: the actor reaches at least one externally reported level
boundary within 32 primitive actions.

- Pass: `levels_completed >= 1` and the report status is `level_gained`, with
  an internally consistent append-only trace. This raises the number of
  distinct game identities with a task-credited actor episode from one to two.
- Fail: no level boundary by action 32, controller/transport failure, or an
  incomplete trace. A behavioral fail means persistence and max reasoning are
  insufficient on this game at this budget; it does not adjudicate every game.

## Information yield

A pass creates the first variation needed to ask which relational features of
two credited episodes can be quotiented while source actions and coordinates
remain task-local. A fail rejects immediate positive-rank expansion through an
unchanged persistent actor on `tu93` and redirects the next test toward active
task selection or within-game generation of multiple credited initiations.

## Claim boundary

Success establishes neither cross-task transfer, a reusable schema,
acquisition savings, catalytic learning, ARC-wide competence, nor literature
novelty. It only raises independent task-credit rank by one.
