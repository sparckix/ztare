# H118 acquisition-derivative schema isomorphism

**Status:** Pre-registered 2026-08-08; no conjecture dispatch had run when this file was written.

## Eigenquestion

What invariant should cross a task boundary when a task-credited motor episode is
expected to reduce the cost of acquiring a later, non-equivalent skill?

## Hypothesis

A typed conjecture transport between task-credited generative skill search and
biological schema consolidation will surface a mother structure outside both
home fields. Its persistent object will not be a source operation word or copied
task credit. It will be an evidence-bound causal abstraction whose target-local
lowering is provisionally admitted only by a commuting witness and whose value is
the matched reduction it causes in later acquisition cost.

## Discriminating test

Run `research_isomorphism.py --mode conjecture --typed-mapping` with:

- a left fingerprint for external task authority, historical skill nomination,
  current carrier lowering, generative macro search, primitive contact cost,
  target-local operations, matched library present/absent acquisition, and
  prediction-error refusal;
- a right fingerprint for episodic traces, replay, schema extraction, cortical
  persistence, local motor instantiation, reward modulation, prediction error,
  transfer, and adaptation cost.

Require every candidate to supply both lowerings, bounded prediction cards,
kill conditions, and a prior-art inversion plan. Manually reject any candidate
that is only DreamCoder-style library compression, option reuse, successor
features, ordinary meta-learning, the existing explicit operation bijection,
H117 generative macros, or H101/H102 capability kinetics.

## Success criterion

At least one schema-surviving candidate names:

1. a substrate-neutral persistent identity distinct from source and target
   operation words;
2. a prospective target-local lowering with a commutation/refusal test;
3. a matched downstream acquisition estimand that subtracts creation,
   retrieval, verification, execution, and error cost;
4. an update rule by which that derivative changes future abstraction or
   morphism selection; and
5. one bounded apparatus discriminator not already implemented in the named
   prior systems or current ZTARE categories.

## Kill conditions

- No candidate survives the typed schema.
- The shared object copies source actions, coordinates, or task outcome.
- The proposal can be reduced to known library learning, option transfer,
  successor features, meta-learning, current skill transport, current
  generative macros, or synthetic capability kinetics.
- Target lowering has no pre-outcome commutation witness or typed refusal.
- Value is stated as reuse, compression, similarity, or reward without a
  matched later-acquisition derivative.
- The update does not alter the next abstraction/morphism search distribution.
- The discriminator requires new ARC contact or treats one frozen boundary as
  evidence for a non-equivalent descendant.

## Claim boundary

A pass selects an algorithmic discriminator. It does not establish biological
fidelity, ARC transfer, catalytic learning, capability acceleration, or
literature novelty. A failure means the conjecture supplied no mechanism beyond
known categories; it does not show that such a mechanism cannot exist.
