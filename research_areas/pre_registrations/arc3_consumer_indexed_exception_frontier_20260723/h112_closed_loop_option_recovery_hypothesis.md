# H112: closed-loop option recovery

Date: 2026-08-06

Hypothesis:
`H-GPSA-CLOSED-LOOP-OPTION-RECOVERY-20260806-112`

Status: pre-registered after H111 settlement and before correction search

## Trigger

H111 found that the fixed H95 suffix succeeds from exactly one of twelve local
states. Treating that word as the skill makes its positive initiation fiber a
singleton. Animal motor skills instead use feedback: deviations select
corrective subprograms, after which the main action chunk can resume.

## Eigenquestion

Are any of H111's distinct fixed-word failures still inside a recoverable
closed-loop option basin, in the precise sense that a short state-conditioned
correction returns the environment to the exact credited H95 initiation state?

## Hypothesis

At least one of the eleven H111 alternative exact states can reach the
canonical H95 source in at most three primitive actions and then complete under
the frozen H95 suffix. The H109 resource/configuration-damaged state cannot.

## Discriminating test

Using the same cached `ls20` source, fixed seed, carrier, and projection:

1. load and verify the H111 exact-state quotient;
2. choose one deterministic representative prefix for each of its eleven
   noncanonical exact states;
3. enumerate correction words in length-then-lexicographic order through
   length three;
4. stop at the first word that reaches the exact canonical grid and factor;
5. execute the frozen eight-action suffix only after exact recovery and verify
   its ordered effect signature and level boundary;
6. run the same correction search from the H109 refusal prefix;
7. compile the recovered cases as a state-keyed branching option receipt whose
   canonical branch uses the empty correction and whose absent branches refuse;
8. mutate source state, correction word, recovered target, suffix effect, and
   environment identity in receipt-only controls.

No model/controller call is permitted. Every environment action is charged.

## Success criterion

Stage A is supported only if:

- at least one distinct H111 source has a correction of length at most three;
- each admitted correction reaches both the exact canonical grid and factor
  before the suffix;
- every recovered branch then reproduces the canonical suffix effect signature
  and gains a level;
- the H109 refusal state has no such correction;
- the branching option is deterministic by exact source identity and refuses
  an unknown source; and
- every mutation is detected.

## Kill and refinement rule

Reject if none of the eleven states is recoverable, if recovery depends on a
coarse state match, if a correction itself crosses the task boundary, if the
post-recovery suffix changes effect identity, or if H109 is admitted. A
rejection means this local neighborhood supplies neither transport variants nor
short feedback repairs. A pass licenses a prospective held-out test of an
induced feedback option, but grants no task credit beyond the exact recovered
paths.

## Claim boundary

Passing would establish one bounded closed-loop expansion of one option basin.
It would not establish a learned general correction rule, held-out transfer,
controller benefit, benchmark gain, catalytic learning, criticality, takeoff,
or literature novelty.
