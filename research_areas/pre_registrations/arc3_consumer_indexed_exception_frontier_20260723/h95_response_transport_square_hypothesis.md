# H95 response-transport square hypothesis

**Status:** supported 2026-08-02; result:
`h95_response_transport_square_result.md`

## Eigenquestion

Can H94's local object-basin response cross one changed observation without
using memory prose, role labels, or embedding similarity, while refusing a
nearby observation where the governing contract cannot be transported?

## Hypothesis

A partial object correspondence compiled from unique, content-addressed object
types can transport H94's contract-relative proposal response from the initial
observation to the observation after one frozen action. The source blind and
revised plan witnesses should form a candidate commuting square in the target
catalog. A new target controller in the transported wrong-control basin should
therefore receive an exploratory causal-memory probe and show the same typed
path displacement.

The intervention itself has two identities. Its acquisition payload,
provenance, provider, calibration, and cost must remain invariant, while its
exact rendered revision changes because the presentation envelope names the
new consumption context. A separate certificate must map the frozen source
revision to the target-scoped revision. Causal and placebo payloads require
different certificates; only the causal certificate may move the learned
response contract.

At the observation after the six-action marker-contact prefix, the required
waypoint occurrence is absent. The compiler must refuse transport without
controller contact.

## Discriminating test

1. Verify the frozen H94 response family, H93 pre/post proposal witness, and H94
   prefix trajectory.
2. Replay action prefix `[2]` and require the frozen target observation and
   catalog identities.
3. Match only source contract and witness objects whose `type_sha256` is unique
   in both catalogs. Do not consume condition names, memory text, role labels,
   embeddings, or H95 outcomes.
4. Reconstruct the frozen source intervention envelope. Compile separate
   causal and placebo source-to-target revision certificates that preserve
   payload, acquisition provenance, provider identity, calibration, and cost
   while changing only the consumption context. Bind the transported contract
   to the causal target revision.
5. Transport the source object-role contract. Verify that the source blind
   basin and revised supported path lower to a candidate commuting target
   square.
6. Before intervention delivery, require each new target blind proposal to
   occupy the transported source basin. Mark the action `explore_transport`;
   it is not promoted credit yet.
7. Run two alternating-order causal-versus-placebo pairs from that prefix with
   3,849 bytes, two proposal calls, and 20 post-prefix actions per arm.
8. Settle uptake and external value in the target fiber. Promote a target
   response only after the randomized settlements pass.
9. Separately replay prefix `[2,2,2,0,0,0]`. Require refusal because the source
   contract's required waypoint has no unique target occurrence. Do not call a
   controller on this negative branch.

## Success criterion

The positive square is a commuting candidate; the negative square refuses;
all four blind controllers start in the transported basin; both targets show
supported path transport; both placebos do not; first stage is `1.0`; target
has nonnegative task delta, positive mean composite delta, and at least one
win; every source, prefix, identity, and fixed-cost check passes.

## Kill conditions

Kill on source or prefix drift, ambiguous object correspondence, forbidden
authority input, a changed intervention payload/provenance/provider/cost, a
certificate reused across causal and placebo payloads, a target contract bound
to the wrong revision, noncommuting positive square, accepted negative square,
target-basin mismatch, post-delivery admission, uptake failure, spontaneous
placebo transport, cost mismatch, task loss, nonpositive mean delta, or zero
wins.

## Pre-controller apparatus correction

The first H95 preflight stopped before manifest creation or controller contact
because it required the source and target rendered intervention revisions to
be equal. The rendered condition envelope includes the consumption scope, so
that equality conflated invariant payload identity with context-local
presentation identity. This revision adds the explicit re-rendering
certificate described above. The live outcome criteria are unchanged.

## Claim boundary

H95 tests one cross-observation response transport and one structural refusal
inside one level. The intervention remains exploratory until target-fiber
settlement. Passing would not establish two-hop path sensitivity, chained
controller credit, cross-task transfer, accelerating gains, ARC benchmark
improvement, or literature novelty.

## Outcome

The positive object and intervention transports compiled; all four blind
proposals occupied the transported basin; causal uptake was `2/2` and placebo
spontaneous uptake was `0/2`. Causal mechanics won both paired composite
comparisons with task delta `+1.0` and mean composite delta `+0.48`. The
negative prefix refused before controller contact. Offline replay verified
the source chain, checkpoints, settlements, and promoted target family.
