## Bug 1 — Gate Harness argparse Failure (fail_other every iteration)

**Observed:** Every iteration logged `fail_other` from gate_harness.py.

**Root cause:** `gate_harness.py` used `argparse`. The loop passes flags like
`--run-visible-assertions` and `--eval_results_path` that argparse rejected as unknown,
causing exit code 2 before any assertions ran.

**Fix:** Rewrote `main()` to use `sys.argv[1:]` pattern matching other sandbox harnesses.
Unknown flags fall through to default (full evaluation). Also fixed in `generate_substrate.py`
`_write_gate_harness_continuous_1var` so future sandboxes are generated correctly.

**Seam:** `generate_substrate.py` harness template; `gate_harness.py`

---

## Bug 2 — Rubric 3-Parameter Ceiling (GP-103 violation)

**Observed:** Rubric persona and criteria contained "3-parameter" numeric ceiling language
generated by `_write_rubric` in `generate_substrate.py`. This was a lethal trap: the
judge would penalize any composite (8-12 parameters) regardless of structural justification.

**Root cause:** `_write_rubric` in continuous mode used numeric parsimony language.
GP-103 checklist was not applied at rubric generation time.

**Fix:**  
1. Updated rubric JSON (all three numeric ceilings replaced with structural justification language).  
2. Updated `_write_rubric` template.  
3. Added Phase 5 blocking gate to `make seal` with auto-scan regex (`\b[0-9]+-parameter\b`).

**Seam:** `rubrics/gp096_sandbox_19_gagorder.json`; `generate_substrate.py`; `Makefile`

## Bug 3 — H-GP103-5 R1 Rejection (Python block missing from seed injection)

**Observed:** Every iteration H-GP103-5 fired, it was immediately rejected at Runner R1.
PHASE_B `validate_python_suite_candidate(None)` raised ValueError.

**Root cause:** The seed injection path in PHASE_A bypasses `mutate_thesis` entirely.
`new_content` = cleaned thesis + fit_declaration block only. No Python block was present.
`_prepare_mutation_candidate` → `validate_python_suite_candidate(None)` → ValueError → R1.
Layer 3 Mandatory never reached because PHASE_B rejected first.

**Diagnosis:** Munger inversion — "why does the system believe no Python block is needed?"
Answer: it never asked the LLM. The seed path is LLM-bypassed.

**Fix:** Append loud-fail sentinel `python` stub to `new_content` at injection site.
Layer 3 Mandatory overwrites stub with deterministic f() before `test_model.py` is written.
Stub never executes. Zero interface changes to downstream phases.

**Recorded:** INV-1 in architectural map, GP-078 spec Implementation Correction section.

## Bug 4 — SciPy Optimization Collapse (warm-start missing from composite seeds)

**Observed:** Every H-GP103-5 composite candidate (after Bug 3 was fixed) achieved
max|res|=1.79947 ± 0.0001. Residual was identical across all 3 starts and all iterations.

**Root cause:** Composite seeds had no `initial_guesses`. SciPy cold-started all parameters
at p0=1.0. For 8-12 parameters spanning 5 log-decades of t ∈ [0.0001, 0.79], the Jacobian
is numerically singular at that start. SciPy escaped by collapsing the second family
amplitude to zero — reducing to a 6-parameter fit with residual ≈ 1.8.

**Diagnosis:** Identical residual across 10 iterations is a deterministic attractor signature,
not stochastic exploration. Karpathy: "If SciPy were exploring, residuals would vary."

**Is this overfitting?** No. Warm-starting does not change topology capacity (the equation
itself). It changes the starting point in parameter space. The distinction:
- **Overfitting** = topology can memorise visible window (equation-level property)
- **Optimization failure** = optimizer cannot find the minimum (calculator-level property)

Gemini Pro: "By passing initial_guesses, you are not changing the capacity of the equation
to overfit. You are simply giving the hiker a map to the correct valley."

**Epistemic isolation value:** After the fix, if the composite holdout gate still fails,
the engine knows definitively the topology was wrong — not the optimizer. Without the fix,
a topology rejection could be a false negative (optimizer failure misread as topology failure).

**Fix (three files):**  
1. `structural_memory.py` `update_structural_memory`: stores `best_visible_fitted_params`
   on first creation and on every best-residual update.  
2. `structural_memory.py` `generate_additive_composite_seeds`: builds prefixed
   `initial_guesses` from historical single-family fitted params.  
3. `autoresearch_loop.py` PHASE_A seed injection: passes `initial_guesses` from
   `_seed_data` into `_seed_fd_dict` → `_seed_fd_block` → `FitDeclaration`.

**Recorded:** INV-8 in architectural map.
